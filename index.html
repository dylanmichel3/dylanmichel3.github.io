Personal systems monitoring and administration service

Oct 2026 - present · Python, Flask, PowerShell, Tailscale, SQLite

A token-authenticated Flask service on my Windows PC, reachable only over Tailscale. It reports system status, wakes other machines on my home network, and runs sleep, restart, and shutdown commands only after a confirmation step. PowerShell scripts check Windows Update compliance every six hours and show pending update titles, the reboot-required flag, and the last installed hotfix on a web dashboard.

Around the service: an event-log digest (Get-WinEvent, last 24 hours, grouped by source and level), a disk-usage analyzer covering per-drive totals and the largest top-level folders, and hourly internet speed tests stored in SQLite with 24h, 7d, and 30d history. Health checks run every 30 minutes and alert only when reachability or disk usage changes state. A patch digest lands weekly and an event digest daily.

Private repository. In daily use at home.
